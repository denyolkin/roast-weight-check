For Artisan users

Check roast weights before relying on them.

Inspect existing .alog files for missing weights and disagreements between raw and cached measurements. Save the findings as a JSON report.

Open Roast Weight CheckDownload for offline use

Free. No account required. Selected roast files are processed on your device and never uploaded. The tool has no analytics. The host receives ordinary page requests.

Try it without a roast file

Open the tool and choose Show synthetic demo. To inspect your own files, choose Artisan files, review the flagged rows, then select Download JSON report.

What the report can tell you

See missing or zero measurements, raw/cache disagreements and incomplete pairs. Conflicts stay unresolved: the tool does not choose an authoritative value or repair the file. Known totals may cover different records and are not an inventory balance.

Supported scope

Desktop Chrome; up to 20 files, each at most 1 MiB; gram weights only. Compatibility with every Artisan version and other browsers is not established. This is a weight inspection utility, not Artisan or an inventory system.
